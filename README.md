# Personal Developer Portfolio

A responsive, editorial-style portfolio starter for an independent web developer. Built with HTML, CSS and vanilla JavaScript; no build step or framework required.

## Included
- Bold editorial homepage with responsive layouts
- Four project case studies: LogicFlow, Bricksleek Legal, BloombyGPTSL and GPTSL, with real homepage screenshots
- Service list and asynchronous/project-based working approach
- WhatsApp and email contact CTAs
- Mobile navigation
- Personal details kept in one configuration file

## Before publishing
1. Open `site-config.js`.
2. Your display name, email and WhatsApp number are already configured in `site-config.js`. Review them before publishing.
3. Your WhatsApp number is formatted for click-to-chat as `2348075114643` (country code + number, digits only).
6. Confirm each project URL and the descriptions accurately represent what is live and what you personally implemented.
7. Add a real domain and configure HTTPS after choosing/registering the domain.

## Preview locally
- Simplest: open `index.html` in a browser.
- Or run a local server from this folder, e.g. `php -S localhost:8000`, then visit `http://localhost:8000`.

## Deployment
Upload `index.html`, `styles.css`, `script.js`, `site-config.js`, and the `assets` folder to the document root of your hosting account. Keep the assets folder alongside the HTML file so the project screenshots load. `README.md` is for your reference and does not need to be public.

## Notes
- Project cards use the homepage screenshots supplied for LogicFlow, Bricksleek Legal, BloombyGPTSL and GPTSL.
- No testimonials, performance metrics, client outcomes or unverified claims have been added.
- Email and WhatsApp contact buttons are configured in `site-config.js`; review the details before publishing.
